
# 🐋 WhaleWatcher — Bitcoin Whale Transaction Tracker

A real-time cryptocurrency monitoring application designed to detect high-value Bitcoin transfers ("whale movements"), track market sentiment, and provide transparent insights into large-scale blockchain activity.

🔗 **Live Application:** [whalewatcherbitcoin.vercel.app](https://whalewatcherbitcoin.vercel.app)

---

## ✨ Key Features

* 📡 **Real-Time Transaction Stream:** Live monitoring of incoming Bitcoin transactions via WebSocket and public blockchain APIs.
* 🚨 **Whale Filtering & Thresholds:** Automatically flags high-volume transfers exceeding custom BTC or USD values (e.g., $1M+ USD or > 100 BTC).
* 🔍 **Detailed Transaction Insights:** Displays exact BTC amounts, current USD equivalent values, sender/receiver wallet addresses, transaction hashes, and confirmation status.
* 📊 **Market Statistics:** Live Bitcoin price feeds, volume metrics, and high-level market activity summaries.
* 📱 **Modern Dark Dashboard:** Fast, clean, and responsive user interface tailored for seamless data monitoring across all devices.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React.js / Next.js
* **Styling:** Tailwind CSS
* **Data & APIs:** Blockchain WebSockets / REST APIs (Mempool.space, Blockchair, or CoinGecko)
* **Deployment:** Vercel
